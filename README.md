## 🏆 수상

### 2026 금융 AI Challenge 우수상 (신한은행장상)
주최 금융보안원 · 후원 금융위원회 · 1,388팀 참가 · [대회 페이지](https://daker.ai/public/hackathons/2026-finance-ai-challenge)

**안심피싱 — AI 기반 불시 보이스피싱 실전 대응훈련 서비스**
AI가 사기범 역할로 실제 전화를 겁니다. 예고 훈련과 불시 훈련의 대응을 비교해 리포트로 보여 줍니다.

- **역할**: AI 파트 (4인 팀)
  - 사기 시나리오 5종과 통화 규칙 설계 (배역·말투·진행 단계, 거절·종료 대응)
  - 녹취 기반 통화 품질 개선
- **개발 방식**: AI 코딩 도구를 활용한 테스트 기반 개발
  - 실제 통화로 시나리오마다 여러 방향의 반응을 반복 테스트
  - DB와 로그에서 예상 밖 응답을 찾아 원인을 고치고 다시 막는 방식으로 수정
- **AI 구성**: OpenAI Realtime 음성 모델 · Cartesia TTS · Silero VAD
  - 응답 지연을 줄이려고 STT → LLM → TTS 구조에서 실시간 음성 모델로 전환
